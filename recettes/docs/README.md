# Documents de conception

Copies locales des pages faites sur claude.ai (le compte d'origine n'est plus utilisé).

- `brief/index.html` : la fiche projet de la V1 (idée, périmètre, écrans, technique, budget). S'ouvre dans un navigateur.
- `maquettes/` : les six écrans de la V1 (Accueil, Recette, Mode cuisine, Ajouter, Relecture du scan, Groupe), au format « Design » de claude.ai, avec `canvas.json` qui les place sur la toile. Ces fichiers ne s'affichent pas seuls (il leur manque le moteur `support.js` de claude.ai) : pour les revoir, demander à Claude de les republier dans une nouvelle toile Design.
